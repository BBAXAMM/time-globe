Planet / dwarf-planet texture provenance
=======================================
All maps below are Solar System Scope textures (https://www.solarsystemscope.com/textures/),
licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Attribution: "Solar System Scope".
The Ceres/Eris/Haumea/Makemake maps are Solar System Scope's "fictional" (artistic, not scientific) maps.
No planetpixelemporium textures are used.
Each file was resized to 1024x512 (Lanczos) and saved as JPEG quality 84 (2026-09-24).
